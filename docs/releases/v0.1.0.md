# SessionGlow v0.1.0 — Ubuntu / GNOME / X11

**Ambient status lights for your OpenCode agents.** See working, completed, failed and attention-needed sessions without switching terminal tabs.

## Included

- Floating PyQt5 panel with five interweaving currents, drifting particles, liquid completion and smooth state transitions.
- One light per main session, including subagent activity and permission/question requests.
- Stable recent-task ordering, bounded local history and reconnection indicators.
- OpenCode terminal, authenticated standalone servers and OpenChamber integration.
- Ubuntu amd64 Debian package, plugin registration/removal commands, English/Chinese landing pages and installation guides.
- Automated Python/Node tests, lint and container-based package lifecycle checks.

## Install

Download `sessionglow_0.1.0_amd64.deb` and `SHA256SUMS` from this release:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./sessionglow_0.1.0_amd64.deb
sessionglow
```

First normal launch registers the plugin for your user. Restart the actual OpenCode terminal/server you use. Preview with `sessionglow --demo`; demo mode does not register a plugin.

## Compatibility and limits

Verified desktop: Ubuntu 22.04.5 / GNOME 42.9 / X11 / amd64. OpenCode 1.18.31 was tested in terminal and server modes, including OpenChamber. Dependencies are system Python 3.10+ and PyQt5 5.15+; `fonts-noto-cjk` is recommended for the current Chinese UI.

Ubuntu 24.04 / Wayland, KDE and mixed DPI remain untested. macOS and Windows are not supported. AppImage is deferred pending runtime/license and lifecycle validation. The panel observes sessions; it does not create tasks or grant permissions.

OpenChamber's backend may use a dynamic port. Restart its actual managed/external service after plugin changes. A browser refresh or project dispose is not a guaranteed plugin reload. Live events do not wait for bounded history restoration, but older sessions may initially have incomplete sorting information.

## Upgrade / uninstall

Close the panel and install the newer package with `sudo apt install ./sessionglow_X.Y.Z_amd64.deb`, then reopen the panel and restart OpenCode.

```bash
sessionglow --uninstall-plugin
sudo apt remove sessionglow
```

Restart OpenCode. The user plugin lives at `~/.config/opencode/plugins/sessionglow.js` (or under `XDG_CONFIG_HOME`). Package removal preserves user settings/history and does not scan home directories. If the package is removed before unregistering, the managed plugin returns no hooks while its source is missing; delete the entry manually when convenient.

Source users should unregister their old user launcher with `python3 install.py --uninstall` before migrating to the package, then launch the package to register its plugin.

## Privacy / license

Only session metadata is sent over localhost; prompts, responses, tool arguments and credentials are not forwarded to the panel. Session titles and project paths are included. MIT applies to SessionGlow's own code; system Python/Qt dependencies retain their licenses.
